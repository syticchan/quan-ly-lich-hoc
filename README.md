# Cách để clone repo vào VSCode
1. Bấm ```F1```, gõ ```Git:Clone```
2. Dán ```https://github.com/syticchan/quan-ly-lich-hoc.git``` vào
3. Chọn folder chứa
> Sẽ giống trong video sau https://youtu.be/Zz2FF5Qu4TE?t=52
